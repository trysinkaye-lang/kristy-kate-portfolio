# SYSTEM / EXPERIENCE

## Commercial objective
The portfolio must make a prospective client trust Kristy Kate Taylor with a real project, not merely admire animation. The interaction system exists to prove range: operational software systems on one side, expressive web experiences on the other.

## Experience architecture
1. Interactive split hero — SYSTEM vs EXPERIENCE, controlled by pointer/keyboard.
2. Full-screen project reel — all seven projects in the intended order; imagery changes as the visitor moves through the list.
3. RBIM flagship proof — long-form software-system sequence with real UI and architecture signals.
4. C.O. Designs proof — image-led creative-development counterpoint.
5. Short about and capabilities — credibility without skill-chip walls.
6. Interactive project starter — helps a prospective client identify a sensible engagement path and links into packages/contact.

## Guardrails
- Actual project work remains the visual identity.
- No particle fields, neon blobs, generic bento cards, glassmorphism, typing terminals, or recognizable React Bits templates.
- Motion cannot be the only source of visual quality.
- Every essential path works with keyboard input and reduced motion.
- Homepage stays shorter than the earlier seven-long-section version; deeper evidence belongs in case studies.
