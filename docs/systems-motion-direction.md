# Systems × Motion — creative direction

This iteration keeps the verified full-stack portfolio architecture and changes the presentation layer around a single idea: **serious software systems shown with expressive, purposeful motion**.

## Phase 1

- **Hero:** oversized role typography is the main visual field. Kristy Kate Taylor's portrait sits inside the typography rather than inside a profile card. Pointer and scroll input create restrained depth; reduced-motion users receive the same static composition.
- **RBIM:** the flagship software project becomes a scroll-led technical sequence. The interface remains the hero asset while supporting copy recedes and architecture signals become more visible as the screenshot expands.
- **C.O. Designs:** the atmosphere changes from system software to spatial creative development. Real project imagery, an actual preview, editorial type, and layered parallax create a distinct architectural identity.

## Guardrails

Motion must explain hierarchy, reveal work, or reinforce the nature of a project. No particles, gradient blobs, glass cards, skill-chip walls, generic bento layouts, looping decoration, or recognizable React Bits template composition. React Bits and Awwwards references are treated as interaction research, not as visual templates.

The remaining homepage projects keep their existing verified implementation until Phase 1 is visually approved. This makes it possible to judge the hero → RBIM → C.O. Designs sequence before extending the motion language to AHDIS, Marci Metzger, Lacomus, ERP, and the design archive.
